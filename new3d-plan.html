new3D · 代码驱动 3D Agent 总体方案

核心思路：agent 生成代码（不是 JSON），代码定义场景结构 + 行为 + 数据契约； 生成后产品按数据契约接入真实数据驱动状态更新；资源按"库 → 混元 → low-poly"三级 fallback，混元结果回写资源库。

② 资源库三级 fallback 流程

flowchart TD
  A[agent 生成代码时需要模型/贴图] --> B[调用 resolve_asset 工具]
  B --> Q{查 manifest 索引}
  Q -->|tag/描述命中| C[返回 asset:id
source=library]
  Q -->|未命中| D[调用混元生成
hunyuan:prompt]
  D --> E{混元结果}
  E -->|成功| F[存入 assets-library
manifest 加条目 write-back]
  F --> C2[返回 asset:id
source=hunyuan]
  E -->|失败/不可用| G[low-poly 程序化几何]
  G --> H[代码内联 low-poly
source=lowpoly]
  C --> Code[生成代码用 loadModel asset:id]
  C2 --> Code
  H --> Code
  Code --> Run[运行时 ResourceManager 解析 asset:id 加载文件]

flowchart LR
  P[自然语言 / 图片] --> Plan[scene_plan

  Gen --> Gate{确定性门控
tsc编译 + 运行时无抛错}

  Gate -->|通过| Shot[截图]
  Shot --> Rev[scene_review
VLM 意图vs渲染打分]

  Rev -->|request-input| User[问用户]
  Rev -->|continue/stop| Done[交付三件套]
  Done --> Export[导出 zip
3d-templete + 生成代码]
