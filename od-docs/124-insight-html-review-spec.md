# Insight HTML 标注与历史版本

日期：2026-10-20

## 范围

在 Insight 普通结果和附件结果的 HTML 工具栏中增加「标注」「历史」，与现有画布入口并列。本次仅改 Insight，复用 Design 的标注弹窗、HTML 标注桥和历史列表面板，不改 Design 调用方或公共组件。

标注和历史均要求文件已落地且处于会话中。未落地的内联/远端 HTML 暂不支持，按钮给出原因。非 HTML 不显示入口。

## 标注

- 在预览视图点击「标注」，选取页面元素并输入备注；已有标记支持查看、双击备注编辑、删除、前后切换。
- 沿用 `uiplusToken` 登录检查，复用公共 `injectCommentBridge`、Design `CommentPopover`。
- 使用已有 `/comment/file` 接口读取、保存和删除，后端按项目目录及会话保存数据。
- 标注文件键使用完整本地路径的 SHA-256，Windows 路径统一分隔符和大小写，避免不同目录同名文件串档及过长目录名。
- iframe 仍为 Blob URL，保持 `sandbox="allow-scripts"`，只在预览副本注入标注脚本；不改原文件。
- 只接收当前 iframe 发出的消息，检查目标坐标和必要字段；保存由宿主弹窗操作触发。
- 文件切换、预览内容变更关闭当前标注弹窗。异步请求绑定发起时的文件/会话，迟到响应不能更新新文件的界面。
- 保存失败保留备注以便重试。已有附件接口回调接入；附件选择入口沿用 Design 弹窗当前隐藏状态，本次不单独开放。

## 历史版本

- 支持桌面端本地 HTML，只记录 HTML 主文件，不快照其外链 CSS、JS、图片。
- 打开文件记录初始版本；文件列表刷新、模型一轮执行结束时为已打开的本地 HTML 检查内容变化，内容一致不重复记录。
- 模型运行期间暂停自动快照和恢复，结束后记录模型版本；其他刷新产生的变化记录用户版本。不会持续监听系统文件修改，外部编辑需刷新后记录。
- 复用 Design `HistoryPanel`，沿用原始版本、用户编辑、模型编辑的标签。
- 存储在源文件目录的 `.history/<完整文件名>.insight/`。每份快照包含时间、来源和 UUID，与 Design 存量历史独立，当前不读取或迁移 Design 历史。
- 快照保留原始字节，写入后比对字节，成功后写 `.ready` 标记；列表忽略未完成写入。同一渲染进程按文件串行记录/恢复。
- 恢复先提示将覆盖当前 HTML，用户点击确认后先备份未记录的当前内容，再写回选中版本并校验。备份失败不会覆盖源文件。
- 恢复完成刷新磁盘预览，并记录恢复结果，恢复前内容可再次选择恢复。
- 当前不自动清理旧版本；没有跨进程独占锁，无法保证与外部编辑器同时写入时的原子性。

## 实现位置

- `components/result-viewer/html-review.tsx`：会话适配、工具栏、历史记录与恢复。
- `components/result-viewer/html-comment-layer.tsx`：当前 iframe 消息、标注弹窗和异步状态。
- `utils/html-comments.ts`：文件身份和公共标注 HTTP 协议。
- `utils/html-history.ts`：字节快照、去重、恢复前备份和版本发布。
- `lib/electron-api.ts`：仅补充已有 `listDirectory` 的局部类型，不改 preload。

以上路径相对于 `packages/app/octoapp/pages/insight/`。

## 验证

- 单元/协议测试：真实临时文件系统覆盖去重、并发、恢复前备份、备份失败不覆盖、文件隔离；本机 HTTP 服务覆盖原会话绑定及保存、读取、删除协议。
- 独立 Chromium 页面使用实际标注桥、弹窗、历史面板与 Insight 组件，覆盖标注新增、编辑、删除、切换文件隔离、历史恢复、源码模式禁用及沙箱属性。桌面 IPC 与标注服务使用测试边界，尚不等于真实桌面部署联调。
- 原画布相关测试、结果页签及埋点回归共 59 项通过；类型检查在 `packages/app` 执行并通过。
