## 三、主要功能模块

### 1. Design / Make 编辑与引用体验（本期核心）

- Design 页面增加 `@` 引用技能和文件的完整入口与选择面板。
- 引入 ProseMirror 编辑器及 Mention、Slash、同步、原子节点等插件。
- 新增设计规范入口并更新 Design Archive 样式。
- 修复局部修改 Line 配置、保存、全屏按钮、画布显示及标注定位。
- Make 设计规划第二阶段修复确认按钮、主 Agent 监控、Tab 展示和输入框锁定。
- 屏蔽 `octo_make` 的 Question 工具，收敛用户交互路径。

### 2. Insight 权限与安全

- 重新设计本地文件权限弹窗，增加独立开发预览页。
- 移除暗色样式并修复 Shell 残留背景、底部间距和路径打开行为。
- 修复 Windows 跨盘符场景绕过 `external_directory` 权限校验的问题。
- 增加文件系统与路径穿越测试，强化跨平台安全边界。

### 3. Insight 产物、上传与下载

- MCP 产物落地幂等状态持久化，避免应用重装后生成同名重复产物。
- Upload Inject 排除本地文件工具，避免上传文件的 Write 落点被替换为 S3 URL。
- 修复输入框附件搬迁判据失效，并将搬迁布局判据收敛为单一真相源。
- Office 中间页下载优先使用本地文件拷贝，本地缺失时回退 Web 下载。
- 文件管理刷新与搬迁逻辑解耦，提高上传链路稳定性。

### 4. 代理与桌面环境

- 增加 W3 代理配置界面。
- 应用启动时从 `~/.config/.octo/config` 注入代理环境变量。
- 修复 `opencode-local.db` 不存在的问题并调整 Desktop 存储逻辑。
- 替换应用 Top Mark 图片。

### 5. Studio 体验与技术方案

- Studio 任务标题改由 LLM 生成摘要标题，避免标题过长。
- 更新模型与页面图标。
- 新增任务全链路取消、提示词优化模型选择和详情标题实现方案文档。
- 调整生成结果解析与 Studio 服务接口。

### 6. 文档与代码整理

- 清理 20 份已过期的 `dev-plan` 文档。
- 新增 3 份 Studio 详细技术方案文档。
- 删除 Tracker 临时调试日志。
- 更新 SDK 类型和接口代码，覆盖新增配置及交互能力。
