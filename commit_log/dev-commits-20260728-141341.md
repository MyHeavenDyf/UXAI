- 重构 Pattern 多 Agent 工作流，包括意图识别、意图确认、规划、模块创建、模块修改、审计与分流。

- 重构 JSON to Code 生成管线，拆分节点映射、代码生成、样式转换、路由生成、文件组装和报告生成。

## 四、主要功能模块

### 1. Pattern / Proto 设计工作流（本期核心）

- Pattern 多 Agent 流程完成集中升级，覆盖意图、规划、模块、修改和审计环节。
- 设计系统与组件使用说明改为通过 Hook 动态加载，降低固定提示词体积。
- 完善意图确认卡片、生成卡片、工具调用卡片、耗时展示和异常提示。
- 增加归档、恢复与资源持久化能力，并修复会话及快速修改稳定性问题。

### 2. Excode 与组件代码生成

- 对 Excode 核心架构进行模块化重构，提升 JSON 到 React/TypeScript 代码的可维护性。
- 扩充 eview-react 组件映射和图表默认配置。
- 增强页面级、Block 级模板匹配和资源索引。
- 支持静态资源导出、样式转换、路由生成及代码生成报告。

### 3. Design / Make

- Design 生成文件支持直接跳转文件夹，并更新文件目录结构。
- 限制版本历史数量，移除排序状态持久化并修复标注时间格式。
- Make 产物自动保存路径迁移到 `.octo/{sessionId}/outputs`。
- 修复模型输出期间按钮和表单仍可操作的问题，并调整消息排序。

### 4. Studio

- 小窗口下优化悬浮抽屉、详情面板、工具栏换行和画布宽度判定。
- 生成过程中允许继续编辑输入框，但禁止发送新任务。
- 修复视频风险提示、初始参数、扩图变形及相关样式交互问题。

### 5. 代理与模型配置

- 代理验证改用显式代理请求，并增加超时、错误输出和目标地址展示。
- 增加跨平台空设备适配、代理 IP 校验及环境变量注入/恢复。
- 清理调试日志和 IPC 返回中的敏感信息。
- 代理设置改用独立 `proxy_config.json`，避免污染主配置。
- 自定义模型供应商支持编辑输入模态，修复模型列表溢出显示。

### 6. Desktop 与工程资产

- Desktop 窗口标题统一为 Octo Agent，并更新版本相关处理。
- Excode 模板迁移为 TypeScript/Vite 工程结构。
- 更新 Preview 静态产物、SDK 生成类型和依赖锁文件。
