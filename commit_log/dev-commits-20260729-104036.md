## 三、主要功能模块

### 1. Insight @ 引用与 Question 答题（本期核心）

- Insight 输入框新增技能和本地文件的 `@` 引用面板。
- 基于 ProseMirror 增加行内引用胶囊，完善键盘输入、删除和选中交互。
- `@` 面板改用 Portal 与 fixed 定位，改善复杂布局下的浮层位置。
- 收敛 Insight 侧面板显示、引用数据和交互问题，并调整「用研资产」相关文案。
- 增加 Question 工具答题 UI，同时放开对应工具权限。

### 2. Design 归档、标注与编辑体验

- 修复归档覆盖问题，归档弹窗默认选中当前项目。
- 修正标注位置，新建标注后自动聚焦输入框。
- Design 对话框支持使用 `Shift+Enter` 换行。
- 优化框选编辑体验，并补充切换模型提示。

### 3. Studio 结果与文件兼容

- 修复标签索引、新结果默认选中、滚动跟随及风格模型抽屉状态。
- 悬浮抽屉展开时隐藏省略号，并修复视频播放器层级。
- 智能重绘结果保留源图比例。
- 修复文件管理中正方形筛选无结果的问题。
- 修复上传文件路径兼容问题并统一部分提示文案。

### 4. 项目版本选择

- 修复版本下拉数据加载完成后面板自动收起的问题。
- 增加守卫定时器代际校验，避免旧定时器误清当前状态。
- 恢复置顶项目的激活状态，避免置顶操作触发错误选择。
- 订正项目版本自动选择的设计口径和说明文档。

### 5. Insight 文件状态与工程文档

- 文件管理视图状态不再写入 `localStorage`，减少跨会话残留状态。
- 新增 Dev 分支提交汇总文档并通过 PR 合入。
