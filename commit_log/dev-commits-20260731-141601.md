## 三、主要功能模块

### 1. Insight 产物类型与文件管理（本期核心）

- 将产物类型判定收敛到单一入口，统一 `resolveOutputType` 相关调用。
- 退役独立的 mindmap、table 类型，将 mindmap 作为内容形态处理。
- 删除 table 相关死链路、双格式导出及归档分支。
- 产物身份改用磁盘路径，去重不再依赖产物类型，内容统一从磁盘读取。
- 移除文件管理预览第四栏，单击文件行后直接在新 Tab 打开。
- 修复文件、图片新页签的归档按钮始终禁用问题。

### 2. Insight 视口与文本交互

- 三列响应式布局对齐 Design 的 Make Layout。
- 完成多轮视口适配评审修复，优化不同窗口尺寸下的布局状态。
- 产物预览区域及任务卡中的报错文本支持选择和复制。

### 3. 任务中心生命周期

- 已完成任务自动从任务中心移除。
- 取消任务后及时更新列表，并完善取消状态与完成回调的时序。
- 修复空列表面板状态、失败项 Hover、定时器句柄和产物过滤问题。
- 收窄任务错误类型，提升任务状态处理的稳定性。

### 4. 模型选择与上下文

- 修复取消勾选模型后，新建对话或切换 Tab 时模型又被自动选中的问题。
- 移除模型选择列表中的能力标签，简化列表展示。
- 为 Octo 模型保留模型上下文，避免切换或调用时上下文丢失。

### 5. Chat / Make / Design 交互

- 修复 Chat 发送消息后无回复且无法停止的问题。
- 修复再次点击 Tab 时技能库未关闭的问题。
- Make 子 Session 活跃时，输入消息始终发送至子 Session，不再误发给主 Session。
- 调整 Design 左侧抽屉宽度。
- Design 发送消息后允许继续输入，不再锁定输入框。

### 6. Studio 与 Pattern / Excode

- Studio 落库时保留编辑结果的 `aspectRatio`，避免被 Provider 返回的空值覆盖。
- 调整 Pattern / Excode 文件命名并修复大小写问题。
- 完成 Pattern 分支同步与合并冲突处理。
