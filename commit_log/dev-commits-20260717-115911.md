## 三、主要功能模块

### 1. Design / Make 附件与结果卡体验（本期核心）

- 改进附件加载方式，区分普通附件与通过 `@` 引用的附件。
- Design 页面调整为仅 Artifact 类型输出结果卡片，减少无效卡片展示。
- 修复全屏按钮消失、代码位置异常以及编辑内容无法正确保存的问题。
- 修复并更新 `/preview` 相关逻辑。
- 调整附件栏、结果查看器、HTML 渲染器、Tab 持久化和 Make 页面状态管理。

### 2. Insight 产物落盘与内网下载

- 产物落盘幂等键由卡片 ID 改为 URI，避免执行“查询结果”等操作后同一产物重复落盘。
- 产物下载改由 Electron 主进程 `net.fetch` 执行，修复内网中“浏览器可达但应用内 fetch failed”的问题。
- 增加本地资源相关测试，覆盖 URI 归一化和幂等场景。

### 3. Insight 日志与结果卡反馈

- 生产构建中支持将 Console 对象安全序列化并落盘，便于问题排查。
- 增加 Console 序列化工具及单元测试。
- 结果卡重试和复制操作增加明确的成功/失败反馈。
- 优化浮层提示组件与样式。

### 4. Studio 工具栏与尺寸校验

- 增加工具栏溢出检测，空间不足时自动收纳操作项。
- 筛选弹框高度根据内容自适应。
- 为不同模型动态应用尺寸校验规则。
- 切换到自定义尺寸时同步宽高输入，并优化即梦模型的警告文案。
- 延后工具栏状态同步，减少切换过程中的视觉抖动。

### 5. Skill 配置与内网适配

- 修复技能配置类型错误。
- 增加内网代码标签相关配置。
- 更新构建配置与依赖锁文件。
- 将上一期 `dev-commits-20260716-103105.md` 正式加入仓库。
