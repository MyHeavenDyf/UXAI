## 三、主要功能模块

### 1. Studio 文件管理与创作体验（本期核心）

- 新增 Studio 文件管理器，支持图片/视频详情视图、筛选和不同 Tab 的独立状态。
- 增加参考图点击复用、参考图上传及参考图反推提示词能力。
- 增加视频角标和时长展示，调整图片/视频模式下的模型切换逻辑。
- 视频筛选模式隐藏不适用的“来源”和“尺寸”选项，弹框高度自适应。
- 优化自定义尺寸弹框关闭行为、详情面板比例显示、输入校验及前导零处理。
- 区分本地、测试和生产环境的 Studio 接口地址。

### 2. Insight 产物统一落盘与文件管理

- Agent 文件产物统一写入会话 `outputs/` 目录。
- MCP URI 产物出卡后立即落盘，使思维导图等生成物能及时进入文件管理。
- URI 来源生成卡自动落盘；Path 来源产物通知文件表格刷新。
- 文件管理面板支持外部 `refreshKey`，上传或产物落地后自动重新拉取列表。
- 移除重复的 URI 卡落盘 Effect，避免同一产物重复处理。
- 修复空文本文件被误判为二进制的问题。

### 3. Insight Tab 与文件交互修复

- 统一不同入口的文件身份标识，避免同一文件被重复打开多个 Tab。
- 修复从文件管理器打开文件时使用错误图标的问题。
- Checkbox 阻止双击冒泡，避免勾选操作触发行双击打开。
- 全选 Checkbox 的 indeterminate 状态改为响应式更新。
- 二进制 Artifact 内容使用 Base64 回退，并修复 ZIP local/central Header 字段偏移。

### 4. Desktop 存储与 SQLite 路径

- 新增桌面端 Storage 模块，集中处理应用数据路径。
- 修复 SQLite 数据库路径问题，降低开发与打包环境之间的路径差异。
- 调整主进程、IPC、Sidecar 和服务启动相关逻辑。

### 5. Skill、Assets 与内网配置

- 增加 `skill_config.json` 和 `assets_config.json` 的读取、写入与同步方法。
- 增加内网代码标签并调整 Skill 相关逻辑。
- 修复 Skills 面板文本。
- 恢复设置中的“自动接受权限”开关。

### 6. Design 文件管理与通用组件

- 调整 Design 页面文件管理面板和工具栏。
- 改进文件列表、筛选及操作入口。
- 增加新组件，并补充全局同步、对话框和 Skill 安装上下文。
