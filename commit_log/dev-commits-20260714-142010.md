## 三、主要功能模块

### 1. Insight 工具集收敛与权限体验（本期核心）

- 收敛 Insight 可用工具集，按使用场景关闭不需要的工具。
- 增加权限询问 Dock，解决访问会话目录外路径时缺少可见反馈的问题。
- 修正 `extract_document` 入口和提示词，支持本地绝对路径以及 TXT/Markdown 直读。
- 用户会话默认关闭 `task`，并拦截子会话导航，避免进入无记录子会话。
- 修复上传注入插件检查顺序：只有真正需要上传注入时才检查 endpoint，避免影响无关工具。
- 增加相关单元测试，覆盖工具权限、上传注入、文档提取和工具注册。

### 2. Insight 文件管理与思维导图导出

- 移除右侧文件预览面板，文件双击改为在标签页中打开。
- 固定面包屑与表格表头，清理预览状态残留，并去重双击埋点。
- 思维导图新增 Octo 白板 JSON 导出。
- 下载菜单中的单一原格式统一显示为“原始格式”。
- Octo 白板文件名统一为 `<原名>_octo.json`。

### 3. 登录态与请求 Header 注入

- 登录后为请求注入 Token 与 Cookie。
- 优化 Token/Cookie 获取方式和请求拦截规则。
- 将拦截范围收窄到前端发起的接口，降低对其他请求的影响。
- 模型 API 请求保留登录 Header，避免认证信息在请求链路中丢失。

### 4. 模型配置与供应商设置

- 新增 models API 客户端，从接口加载 W3 模型配置。
- 简化模型供应商相关设置控件。
- 调整默认模型、模型列表、供应商和本地模型上下文的加载逻辑。
- 补充模型 Header 插件及相关服务端接口处理。

### 5. Studio 图片生成体验

- 增加生成结果所使用参考图的展示。
- 优化参考图数据存储和会话缩略图处理。
- 自定义图片宽高通过 `extra` 字段传递。
- 更新 Studio 页面、会话解析逻辑、类型定义、样式及测试。

### 6. Skill 配置机制

- 引入 `skill_config.json`，结构区分 Skill 配置与各 Agent 的技能列表。
- Agent 可按 `octo_insight`、`octo_make`、`octo_studio` 类型过滤技能。
- 新增配置文件自动创建、旧 `skills.json` 回退和同步更新机制。
- 增加单元测试覆盖 Agent 过滤、回退和权限场景。

### 7. 对话渲染与开发配置

- 修复对话文本中的 HTML 转义问题，并新增 Markdown 渲染测试。
- 增加内外网开发说明和桌面端环境配置。
- 调整桌面窗口、IPC、预加载和渲染入口相关配置。
