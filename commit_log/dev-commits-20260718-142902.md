## 三、主要功能模块

### 1. Insight 文件与产物链路（本期核心）

- 文件管理增加预览面板并支持图片类型渲染。
- 图片“添加至会话区”改走 S3 上传，修复发送时附件丢失。
- 产物落点改由服务端确定性重定向，移除每轮注入的绝对路径提示。
- 修复“打开所在文件夹”在文件不存在时静默失败的问题。
- 将 `writeFileBuffer` 补入类型化 Desktop API，移除不安全的类型绕过。
- 修复侧栏改名后目录信息和顶部标题不同步。

### 2. Artifact、下载与网络请求

- 多选打包 ZIP 修复中文文件名乱码、同名覆盖和 Windows 无法打开。
- Desktop 资源下载由浏览器 `fetch` 改为 Electron `net.fetch`。
- Pipeline 请求改为浏览器直连，失败时通过 Toast 反馈并移除死错误态。
- 调整网络错误策略，部分非关键请求失败不再阻断主流程。

### 3. Studio 状态与交互体验

- 跨 Session 保存文件管理以及图片/视频 Tab 的选中状态。
- 跨 Tab 持久化视图模式并修复图片分辨率显示。
- 恢复视频权限检查，优化文件管理和画布交互。
- 修复重新编辑、图标和样式问题。
- 放开 Webview 跨域策略，适配资源预览和加载。

### 4. 聊天排队与界面体验

- Chat 和 Design 增加对话排队组件。
- 聊天区域滚动底部增加渐变遮罩。
- 修复结束对话后队列未清空以及滚动组件问题。
- 修复 Design 新建对话与聊天区域所选模型不一致。
- 调整 Insight 输入框样式并补齐附件移除回调。

### 5. Skill、MCP 与模型配置

- `/skills` 复用 Insight 侧栏并统一宽度、折叠布局。
- Skill 按文件夹名称进行 Agent 过滤，并修复自定义 Skill 逻辑。
- MCP 重连机制改为按需阻塞重连并增加 Toast 通知。
- 模型消息处理支持特定模型请求格式。
- Octo Provider 名称改为从模型快照读取。

### 6. 登录态、日志与 Design

- Desktop 增加 Token 和 Cookie 刷新机制。
- 修复两处 Insight 失效文档引用。
- 更新 Skills 面板与标注功能信息。
- 修复 Design 参数漏传问题。
- 将上一期 `dev-commits-20260717-115911.md` 加入仓库。
