### Path
> 路径绘制组件
- 构造: `new Path(options: PathOptions)`

Options:
- `paths` (PathData[]) 默认 `—` — 必填。一组路径数据，每个元素生成一条管道或扁平带
- `material` (THREE.Material) 默认 `—` — 共享材质（所有路径复用）。不传则使用默认 MeshStandardMaterial（dispose() 时一并释放）
- `name` (string) 默认 `—` — Object3D.name
- `visible` (boolean) 默认 `true` — 是否可见
- `userData` (object) 默认 `—` — 自定义数据
- `children` (Object3D[]) 默认 `—` — 额外子节点，自动 add()
- `flow` (FlowOptions) 默认 `—` — 流光效果配置。开启后一条带拖尾的高亮光带贯穿整组 paths（从第一条流向最后一条）。流光材质由组件 clone 生成并独立释放

DataTypes:
- **FlowOptions**:
  - `enabled` (boolean) 默认 `false` — 是否开启流光
  - `color` (ColorRepresentation) 默认 `0xffffff` — 流光颜色
  - `speed` (number) 默认 `1` — 流动速度（全局圈/秒）
  - `direction` (1 | -1) 默认 `1` — 流动方向：1 = 第一条 → 最后一条，-1 = 反向
  - `width` (number) 默认 `0.25` — 光头亮带占流光总长度的比例（0-1，越大光头越宽、拖尾越短）
  - `tailLength` (number) 默认 `0.4` — 流光总长度（归一化到全局 [0,1]）；光头与拖尾按 width 比例分配，长度变化时拖尾始终可见
  - `intensity` (number) 默认 `2` — 流光强度（emissive 叠加倍率，可 >1 求 HDR 发光）
  - `repeat` (number) 默认 `1` — 全局流光个数（沿整组 paths 等间距分布）
- **PathData**:
  - `path` ([number, number, number][]) 默认 `—` — 必填。路径顶点（3D）。相邻重复点自动去重；少于 2 个有效点时该条跳过
  - `mode` ('tube' | 'plane') 默认 `'tube'` — 生成模式：'tube' = 圆管扫掠；'plane' = 扁平带状面
  - `bevelRadius` (number) 默认 `0` — 拐角圆角半径。> 0 时拐角用二次贝塞尔曲线倒圆角；0 时为纯折线（直角拐角）
  - `close` (boolean) 默认 `false` — 路径是否自动闭合（首尾相连成环，需 ≥ 3 个顶点）
  - `up` ([number, number, number]) 默认 `—` — up 向量，决定标架法向（进而决定平面带朝向与管道截面起始朝向）。不传则用 Frenet 自动选取（与 three.js TubeGeometry 一致）
  - `divisions` (number) 默认 `12` — 非直线段（贝塞尔曲线）的采样分段数
  - `uvMode` ('repeat' | 'stretch') 默认 `'repeat'` — 贴图沿路径方向的映射：'repeat' = 按物理长度平铺（u = 弧长 / 截面周长或带宽，配合 RepeatWrapping 可重复贴图）；'stretch' = 一张贴图从头铺到尾（u 归一化到 [0,1]）
  - `radius` (number) 默认 `0.1` — 管道半径（≤ 0 时该条跳过）
  - `radialSegments` (number) 默认 `8` — 圆周分段数（越大越圆滑，最小 2）
  - `startRad` (number) 默认 `0` — 截面起始角偏移（弧度）
  - `generateStartCap` (boolean) 默认 `false` — 是否生成起点封盖（需 radialSegments ≥ 3）
  - `generateEndCap` (boolean) 默认 `false` — 是否生成终点封盖（需 radialSegments ≥ 3）
  - `width` (number) 默认 `0.1` — 带宽（≤ 0 时该条跳过）
  - `side` ('both' | 'left' | 'right') 默认 `'both'` — 带相对中心线的偏侧：'both' 居中、'left' / 'right' 仅一侧
  - `sharp` (boolean) 默认 `false` — 是否在锐角拐角做几何修补（避免带面撕裂）
  - `arrow` (boolean) 默认 `false` — 末端是否生成箭头

- `dashInvert` (boolean) 默认 `true` — 虚线是否反转（亮 / 暗段互换）
- `dashRepeats` (number) 默认 `4` — 虚线重复次数（每条边重复几段）
- `dashLength` (number) 默认 `0.5` — 虚线一段中「亮」的占比（0–1）
- `squeeze` (boolean) 默认 `false` — 是否启用中间收窄（线条向段中心变细）
- `squeezeMin` (number) 默认 `0.2` — 收窄最小值
- `squeezeMax` (number) 默认 `1` — 收窄最大值
- `renderOrder` (number) 默认 `0` — 渲染顺序
- `toneMapped` (boolean) 默认 `false` — 是否参与色调映射
- `overrideMaterial` (boolean) 默认 `false` — 是否覆盖父级材质（onBeforeCompile 注入），而非生成独立线框网格。true = 把线框融入原 PBR 渲染，适合「带光照的线框化模型」，此模式下 fillMix 生效
- `name` (string) 默认 `—` — Object3D.name
- `visible` (boolean) 默认 `true` — 是否可见
- `userData` (object) 默认 `—` — 自定义数据
- `children` (Object3D[]) 默认 `—` — 额外子节点，自动 add()
