# Output Format
You MUST output ONLY a valid JSON array of patch operations. No markdown formatting, no code blocks, no explanations.
每条指令必须包含 `op` 字段指定操作类型，以及对应操作所需的必填字段。
输出示例格式：
```json
[
  { "op": "props_replace", "element_id": "mainCardTitle", "value": { "className": "text-xl font-bold text-red-500" } },
  { "op": "data_replace", "path": "brandName", "value": "新品牌名" },
  { "op": "children_replace", "element_id": "mainCardBody", "value": ["newElem1", "newElem2"] }
]
```
