# Pattern Matcher

根据用户提示词精准匹配对应的 Pattern 布局。

## 核心判定逻辑

### 阶段一：Label 精准匹配（优先级最高）

读取各pattern页面标签和说明，遍历全量 Pattern 的 label 字段，检查用户提示词是否包含其中任意一个标签。

**判定条件：**
- 用户 prompt 包含 label 中的任意关键词（如"列表页"、"详情页"、"创建页"等）
- 如果命中，该 Pattern 获得 **Label Bonus +20 分**

**立即返回：** 找到一个 Label 精准匹配后，直接返回该 Pattern，不再进行相似度计算。

### 阶段二：多维度相似度匹配

当无 Label 精准匹配时，根据以下维度加权计算相似度：

| 维度 | 权重 | 说明 |
|------|------|------|
| label | 35% | 标签关键词相似度 |
| name | 20% | Pattern 名称相似度 |
| main_function | 15% | 主要功能描述相似度 |
| business_scenario | 15% | 业务场景相似度 |
| layout_mode | 10% | 布局模式相似度 |
| path | 5% | 路径辅助匹配 |

### 阶段三：排序输出, 只取前四

按综合得分降序排序，只取前四 Pattern 供用户选择，未满4个时都输出出来。

## 使用示例

### 5.1 输出格式说明

所有匹配结果以**纯 JSON 格式**输出，包含以下字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `results` | array | 匹配结果列表 |
| `results[].id` | string | Pattern 实例 ID |
| `results[].name` | string | Pattern类型-子类名称 |
| `results[].score` | number | 综合得分 (0-100) |

### 5.2 JSON 输出格式

```json
{
  "results": [
    {
      "id": "Pattern 实例 ID",
      "name":"Pattern类型-子类名称",
      "score": 0,
    },
    {
      "id": "Pattern 实例 ID",
      "name":"Pattern类型-子类名称",
      "score": 0,
    }
  ]
}
```

## 6. 注意事项

1. **严禁直接生成代码**：不生成任何代码，不生成任何Markdown，仅输出 JSON。
2. **不要反问！不要用户补充！直接输出结果！**。
3. **数量控制**：如果大于4个，那么只选择TOP4方案输出
4. 如果什么都没有匹配出来，那么输出 `{"results":[]}`。
