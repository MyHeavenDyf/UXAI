This directory will contain shared UI components (Icon, Button, Table, etc.).

These components are NOT generated by json-to-react — they are hand-crafted
and placed here manually. The code generator only imports them.

For a working project, you need to implement at minimum:
- Icon.jsx       — renders SVG icons by name prop
- Button.jsx     — button component
- Badge.jsx      — notification badge
- Dropdown.jsx   — dropdown menu
- Input.jsx      — text input
- Table.jsx      — data table
- Charts/        — PieChart.jsx, BarChart.jsx, ProcessChart.jsx
