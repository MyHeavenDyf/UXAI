# 内外网开发模式说明

> 本文用于持续记录项目在外网与内网环境中的开发、同步、合并和运行方式。后续有新信息时继续补充，不将尚未确认的推测写成既定规则。

## 1. 环境划分

项目开发分为外网和内网两个相互隔离的环境。

### 外网环境

- 当前 Git 项目位于外网环境。
- 外网仓库是可以正常进行 Git 管理和代码开发的项目来源。
- 外网代码允许传入内网。

### 内网环境

- 内网项目通过下载外网 Git 项目后，在内网保存并继续开发。
- 内网无法将代码、配置、日志或其他内容传回外网。
- 数据和代码流向是单向的：外网可以进入内网，内网不能返回外网。

```text
外网 Git 项目 ──────允许──────> 内网开发项目
外网 Git 项目 <─────禁止────── 内网开发项目
```

## 2. 当前代码合并方式

外网代码与内网代码合并时，以目录文件合并的方式处理：

```text
外网项目根目录/packages/**
                +
内网项目根目录/packages/**
                ↓
合并 packages 下的所有文件
```

当前方式的特点和风险：

- 合并范围是根目录下整个 `packages` 目录，不只是业务源代码。
- 位于 `packages` 下的环境文件、构建配置和其他环境相关文件也可能被覆盖或产生冲突。
- 内外网差异配置不适合直接硬编码在双方都会合并的文件中。
- 内网产生的修改不能直接传回外网，因此需要在外网根据问题描述重新实现对应修改。

## 3. 模型配置要求

### 3.1 配置来源

外网和内网当前都要求通过 HTTP 获取模型配置：

```env
VITE_OCTO_MODELS_API_SOURCE=http
```

内外网应分别使用各自环境中可访问的 `VITE_OCTO_MODELS_API_URL`：

```text
外网环境 → 外网可访问的模型配置 HTTP 地址
内网环境 → 内网可访问的模型配置 HTTP 地址
```

这些地址返回的模型配置数据中包含 provider、model 和 provider API 地址等信息。

### 3.2 W3 API 地址

W3 对话模型的 API 地址应来自 `VITE_OCTO_MODELS_API_URL` 返回数据中的：

```json
{
  "w3": {
    "api": "http://example.internal/v1",
    "models": {}
  }
}
```

期望调用链路：

```text
VITE_OCTO_MODELS_API_URL
  → 请求 api.json
  → 读取 w3.api
  → 将 w3.api 传给 OpenCode 服务端
  → 服务端使用该地址创建 W3 SDK
  → 向该 HTTP 地址发送对话请求
```

在 `VITE_OCTO_MODELS_API_SOURCE=http` 时，不应因为远端配置传递失败而静默使用本地快照中的 `w3.api`，否则会掩盖真实配置问题。

## 4. 已确认的内网现象

- 内网环境可以正常请求 `VITE_OCTO_MODELS_API_URL`。
- 内网可以看到该 URL 返回的数据，数据内容正常。
- 内网环境配置的 `VITE_OCTO_MODELS_API_SOURCE` 是 `http`。
- 曾出现修改本地快照中的 `w3.api` 后，对话模型 API 地址随之变化的现象。
- 上述现象说明 HTTP 配置虽然已在前端成功获取，但 `w3.api` 在部分调用链路中没有传递到服务端，随后使用了本地快照兜底。

## 5. 已处理的相关调用链路

目前围绕 W3 HTTP API 来源做过以下处理：

- 前端从远端模型配置中提取 `w3.api`。
- 前端通过 `x-opencode-w3-api` 请求头将地址传给服务端。
- 服务端优先使用传入的远端 W3 API 地址。
- W3 模型缓存键包含实际 API 地址，地址变化后不继续复用旧 SDK 实例。
- Hono Session 路由会读取模型配置请求头。
- Effect HttpAPI 的普通 `prompt`、`promptAsync` 和 V2 `prompt` 也会读取模型配置请求头。

## 6. 配置优先级注意事项

前端当前允许 `localStorage` 覆盖构建时环境变量：

```text
opencode.modelsApiSource
opencode.modelsApiUrl
```

有效值的优先级是：

```text
localStorage
→ VITE_OCTO_MODELS_API_SOURCE / VITE_OCTO_MODELS_API_URL
→ 默认值
```

因此排查环境差异时，需要同时检查构建日志、环境变量和 `localStorage`，不能只检查 `.env` 文件。
