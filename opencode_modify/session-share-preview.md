# 分享弹窗真实聊天预览

弹窗改为分页、只读预览当前会话，打开弹窗不会导出 ZIP、上传或执行产物。
生成链接仍使用原来的 `/session/:sessionID/portable-share` 流程。

## 数据接口

`GET /session/:sessionID/share-preview?limit=20&before=...`

沿用原有目录请求头、授权及实例路由。Hono 和 Effect HttpApi 均提供此接口。
返回 `messages`、可选的历史游标 `before`、是否仍在生成的 `running`。
每条消息只包含 `id`、`role`、`text`、`truncated` 和附件 `files: [{ name, mime }]`。

- 默认及最大每页 20 条，使用数据库时间及 ID 游标向前分页。
- 查询投影不加载完整消息或工具 Parts；不返回推理、工具输入输出、文件 URL、Base64 或文件二进制。
- 每条最多预览 16 个正文/文件 Parts，正文最多 8192 个 JS 字符。
- 用户正文与 Design 主聊天页一致：优先采用 `metadata.displayText`；否则取第一个文本 Part 中最后一个 `\n---\n` 之后的内容，不拼接额外的内部提示 Part。先在 SQLite 去除上下文，再限制返回长度，长目录/产物列表不会挤掉真实输入。
- SQL 中也限制 Part 数量及字段长度，避免先读出大字段再在前端裁剪。
- 空正文页仍返回游标，可继续查看更早记录。

## 前端性能与行为

- 预览窗口高 280px，按可见区域和上下 200px 缓冲挂载消息。
- 隐藏滚动条，仍支持滚轮、触控板及键盘滚动；底部仍有内容时显示渐隐模糊，到底或内容不足一屏时隐藏。
- 通过 ResizeObserver 测量消息高度；加载历史时保留滚动锚点。
- 内存最多保留 100 条消息；超出时淘汰较新记录，可通过“回到最新”重新加载。
- 长于 360 字的正文默认折叠，展开后才解析完整预览 Markdown。
- Markdown 禁用原始 HTML、外部图片和可点击链接，不做代码语法高亮，不挂载聊天业务组件。
- 用户输入保持纯文本，不将其 Markdown 标记转换为助手样式。
- 助手正文中的真实 `<artifact>` 块使用现有纯解析器转为文件卡片，隐藏 HTML 等产物源码；保留周围说明文字与普通代码示例。只解析有长度上限的已加载文本，不保存产物、挂载 iframe 或执行脚本。
- 使用独立的 Marked 实例，避免 App 全局异步语法高亮扩展影响同步只读预览。
- 请求进行中禁用重复操作，15 秒超时后可重试；关闭弹窗中止请求、释放观察器和事件监听，不保留全局无限缓存。
- 复用已有事件流，仅提示“对话有更新”，不逐 token 重绘或额外轮询。
- 预览精简不裁剪 ZIP 内容；最终分享以点击“复制链接”时后端生成的快照为准。

## 验证

覆盖千条消息、百万字符正文、工具大输出、附件、纯隐藏消息页、游标和两套后端的错误码一致性。
前端覆盖窗口范围计算、Markdown 安全及浏览器内分页、刷新、展开、重试、空态、关闭取消请求。
